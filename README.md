# Zaika Indian Cuisine — Treasure Coast

Production-ready static website for Vercel.

## Publish updates through GitHub
1. Replace the existing files in the `zaika-website` repository with the contents of this folder.
2. Commit the changes to the `main` branch.
3. Vercel will redeploy automatically.

## Confirm before public launch
- Add the exact restaurant street address.
- Confirm menu items and prices.
- Replace the reservation/order placeholders with live links.
- Add Instagram and Facebook links.
- Connect the inquiry form to a form provider or reservation platform.
- Add the custom domain under Vercel → Project → Settings → Domains.
